# \# Video Playlist Manager

# 

# Video Playlist Manager is a MERN web application developed for IFQ636 Software Lifecycle Management.

# 

# \## Features

# 

# \- User registration and login

# \- Playlist creation and management

# \- Add videos to playlists

# \- Remove videos from playlists

# \- Playlist deletion

# \- Administrator dashboard

# \- MongoDB Atlas integration

# \- AWS EC2 deployment

# \- GitHub Actions CI/CD pipeline

# 

# \## Technologies Used

# 

# Frontend:

# \- React

# \- Axios

# \- React Router

# 

# Backend:

# \- Node.js

# \- Express.js

# \- MongoDB Atlas

# \- Mongoose

# \- JWT Authentication

# \- bcrypt

# 

# Deployment:

# \- AWS EC2

# \- PM2

# \- GitHub Actions

# 

# \---

# 

# \## Local Setup Instructions

# 

# Clone repository:

# 

# ```bash

# git clone YOUR\_REPO\_URL

# ```

# 

# Install dependencies:

# 

# ```bash

# npm install

# npm install --prefix backend

# npm install --prefix frontend

# ```

# 

# Backend setup:

# 

# Create:

# 

# ```text

# backend/.env

# ```

# 

# Example:

# 

# ```env

# MONGO\_URI=your\_connection\_string

# JWT\_SECRET=your\_secret

# PORT=5001

# ```

# 

# Run backend:

# 

# ```bash

# npm run dev --prefix backend

# ```

# 

# Run frontend:

# 

# ```bash

# npm start --prefix frontend

# ```
